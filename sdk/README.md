# Nexus Plugin SDK

WIT IDL definitions for the Nexus plugin system, plus language bindings
generated by [wit-bindgen](https://github.com/bytecodealliance/wit-bindgen).

## Directory layout

```
sdk/
├── wit/                          # WIT interface definitions (source of truth)
│   ├── nexus.wit                 # top-level world
│   └── nexus/                    # interface files (types, exports, host imports)
│       ├── types.wit             # shared types
│       ├── plugin.wit            # plugin exports (entry points)
│       ├── storage.wit           # host: object storage
│       ├── vector.wit            # host: vector search
│       ├── state.wit             # host: state KV
│       ├── event.wit             # host: event subscribe/publish
│       ├── observability.wit    # host: log/metric/trace
│       ├── http.wit              # host: outbound HTTP
│       ├── stream.wit            # host: streaming body I/O
│       ├── route.wit             # host: HTTP response + SSE
│       └── task.wit              # host: cron scheduling
├── rust/                         # Rust bindings (generated)
│   └── nexus-plugin-sdk/
└── go/                           # Go (tinygo) bindings (generated)
    └── nexus-plugin-sdk/
```

## Regenerating bindings

Bindings are checked in so plugin authors don't need wit-bindgen installed
to consume the SDK. Regenerate after editing WIT:

```bash
# Pin wit-bindgen version (spec §8.8 — version drift protection)
WIT_BINDGEN_VERSION=0.30.0

# Rust bindings
wit-bindgen rust --out-dir sdk/rust/nexus-plugin-sdk/src sdk/wit

# Go bindings (tinygo target)
wit-bindgen go --out-dir sdk/go/nexus-plugin-sdk --target tinygo sdk/wit
```

## Versioning

- IDL package version: `nexus:plugin@1.0.0` (matches manifest `api_version`)
- Rust crate: `nexus-plugin-sdk = "1.0"`
- Go module: `github.com/cipherlake/nexus/sdk/go/nexus-plugin-sdk v1.0.0`

Major bumps break ABI (plugins must recompile); minor bumps add imports
backward-compatibly; patch bumps are bug fixes. See spec §3.15.

## Plugin author quickstart

### Rust

```rust
// Cargo.toml
[dependencies]
nexus-plugin-sdk = "1.0"

// src/lib.rs
use nexus_plugin_sdk::exports::nexus::plugin::exports::{wasm_init, on_request};
use nexus_plugin_sdk::host::state;

nexus_plugin_sdk::export!(MyPlugin);

struct MyPlugin;

impl on_request::Guest for MyPlugin {
    fn on_request(token: u64, route_id: u32, req_handle: u64) -> u32 {
        // Read request body via host import...
        // Store something in state:kv...
        let _ = state::put(token, "last_invocation".as_bytes(), b"ok", None);
        0
    }
}
```

### tinygo

```go
//go:build tinygo.wasm

package main

import (
    "github.com/cipherlake/nexus/sdk/go/nexus-plugin-sdk/host/state"
    nexus "github.com/cipherlake/nexus/sdk/go/nexus-plugin-sdk/exports"
)

func main() {}

//export wasm_init
func wasmInit(token uint64) uint32 { return 0 }

//export on_request
func onRequest(token uint64, routeId uint32, reqHandle uint64) uint32 {
    state.Put(token, "last_invocation", []byte("ok"), nil)
    return 0
}
```
